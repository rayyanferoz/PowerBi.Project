# 📊 Data Jobs Dashboard 2.0

> A streamlined Power BI dashboard for exploring the 2024 data science job market.

## 🚀 Introduction

The data job market contains a huge amount of information, but finding useful insights can be difficult.

**Data Jobs Dashboard 2.0** turns real-world 2024 data science job postings into a focused, interactive dashboard designed to help **job seekers, career switchers, and anyone exploring data careers** quickly understand job demand, salaries, skills, and locations.

This is the **second iteration** of my Data Jobs Dashboard, with a stronger focus on simplicity, interactivity, and efficient storytelling.

## 🎯 Key Insights

The dashboard allows users to explore:

- 💼 **Job Count** — Understand demand across data roles
- 💰 **Median Salaries** — Compare yearly and hourly compensation
- 🛠️ **Skills Per Job** — Explore the skill requirements of different roles
- 📊 **Skill Popularity** — Compare the most in-demand skills
- 💼 **Job Title Comparison** — Analyze salaries across different positions
- 📍 **Job Locations** — Explore the geographic distribution of opportunities

## ⚙️ Power BI Skills Demonstrated

- 🧹 **Power Query** — Data cleaning, transformation & ETL
- 🔗 **Data Modeling** — Relationships & Star Schema principles
- 🧮 **DAX** — Measures, calculations & aggregations
- 📊 **Data Visualization** — Column, Bar, Line, Area & Card visuals
- 🗺️ **Geospatial Analysis** — Mapping job locations
- 🎚️ **Slicers** — Interactive filtering
- 🔘 **Buttons & Bookmarks** — Report navigation
- 📋 **Tables & KPIs** — Detailed data and key metrics

## 🖥️ Dashboard Design

Unlike the first version, **V2.0 focuses on a single-page experience**.

The dashboard is designed as a compact **"mission control"** for the data job market, bringing the most important metrics and comparisons together without requiring users to navigate through multiple pages.

This iteration also focuses more heavily on **interactive filtering and efficient visual storytelling**.
